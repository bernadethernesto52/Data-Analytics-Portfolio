Projeto Power BI 2
Descrição

Segundo projeto prático de análise e visualização de dados, desenvolvido com Microsoft Power BI.

Competências aplicadas:
Transformação e preparação de dados.
Modelação de dados.
Criação de medidas DAX.
Construção de dashboards interativos.
Visualização e interpretação de resultados.

Ferramenta utilizada:
Microsoft Power BI Desktop
