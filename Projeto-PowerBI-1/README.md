Projeto Power BI 1
Descrição

Projeto prático de análise e visualização de dados, desenvolvido durante o processo de aprendizagem em Data Analytics.

Competências aplicadas:
Importação e transformação de dados com Power Query.
Modelação de dados e criação de relações entre tabelas.
Criação de medidas e fórmulas DAX.
Desenvolvimento de dashboards interativos.

Ferramenta utilizada:
Microsoft Power BI Desktop
